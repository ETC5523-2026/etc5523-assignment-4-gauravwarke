## Count and compare hot days

The fire-season functions the app is built on.

- [`count_hot_days()`](https://etc5523-2026.github.io/etc5523-assignment-4-gauravwarke/reference/count_hot_days.md)
  : Count very hot days in each bushfire season
- [`compare_periods()`](https://etc5523-2026.github.io/etc5523-assignment-4-gauravwarke/reference/compare_periods.md)
  : Compare hot days in an early period with a recent period
- [`describe_change()`](https://etc5523-2026.github.io/etc5523-assignment-4-gauravwarke/reference/describe_change.md)
  : Describe a change between two periods in plain English
- [`fire_season()`](https://etc5523-2026.github.io/etc5523-assignment-4-gauravwarke/reference/fire_season.md)
  : Label the bushfire season a date belongs to
